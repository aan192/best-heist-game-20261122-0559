# GETAWAY GRANNY: The Museum of Moonlight Heist

An original 2D top-down stealth heist game built in plain JavaScript & Canvas with no external assets and no network dependency.

## Game Description
Sweet grandma (pink knit shawl, silver hair bun, handbag, and mobility scooter) is on a mission to rob the prestigious Museum of Moonlight. Navigate through 3 security zones (Gallery Hall, Vault Corridor, and Diamond Chamber), dodge patrolling guards with yellow vision cones and sweeping ceiling security cameras with cyan cones, distract guards with delicious cookies, secure the legendary Moonlight Diamond, and zip back to your green mobility scooter parked outside for a clean getaway!

## Controls
- **Movement**: Arrow Keys or WASD
- **Toss Cookie**: C (distracts nearby guards for 3 seconds; 3 cookies available)
- **Pause**: P
- **Mute**: M
- **Restart**: R
- **Title Start**: Space or Enter

## How to Run
1. Serve the game locally:
   ```bash
   node serve.ts
   ```
2. Open your browser at `http://localhost:8080`.
3. To build the dossier and bundle output:
   ```bash
   node main.ts
   ```
